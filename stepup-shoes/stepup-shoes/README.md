# StepUp Shoes - React + Vite + Tailwind CSS v3

## Run on Windows
1. Install Node.js (LTS) from nodejs.org
2. Open this folder in VS Code, then open the terminal
3. npm install
4. npm run dev  (open the link shown, usually http://localhost:5173)

## Features
- Shop with category filter, search and price sort
- Product page with size and color selection
- Cart (quantity, remove) and checkout form
- Admin panel at /admin (demo password: admin123): add, edit, delete shoes and view orders
- Product pictures are in public/images (shoe-1.svg to shoe-12.svg). Replace them with your own photos using the same file names, or paste an image path/URL in the admin form
- Data is stored in the browser's localStorage (no backend)
